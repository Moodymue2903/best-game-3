OCR on the cover confirms MONSOON PERCH. Monsoon is the second-least-saturated of the seven islands. ## Fix 2 — Top HUD pills crowd the wordmark banner on the cover (HIGH, ~15 min)
render.js lines 1126–1130 bake the SKYFLOCK wordmark into goldPanel(ctx, 360, 84, 560, 100, 18) — spans y=84–184. Top HUD pills sit at y=14–60. They don't overlap geometrically, but the cover now has 3 stacked horizontal bands: HUD pills → wordmark banner → Skytree. OCR barely reads the WAVE pill ("ae)" garbage) because the small HUD text is squeezed above a giant wordmark. Fix: in shots.js cover staging, after state.coverWordmark = true, also set state.coverHideTopHud = true, and in drawHUD() early-return for the top bar (lines 693–725) when the flag is set. Bottom HUD (Skytree hearts, Nesting Chest, relic chips) stays — those are the dense "alive" elements. Just kill the top pills so the wordmark reads alone. ~10 min, single if guard.

## Fix 3 — Victory screen stat panel unreadable in OCR (MEDIUM, ~30 min)
OCR on 4-victory.jpg returns essentially nothing inside the gold panel (garbage: "Saar FE a / s& / TU ..."). Headline SANCTUARY SAVED! reads, subtitle reads, stat panel (render.js rows 1015–1027: FINAL SCORE / ROOSTS / CROWS ZAPPED / WAVES CLEARED / NESTING CHESTS) does not. Pixel analysis: dominant #0f0a1e (0.93 backdrop), second #1d2a6e (panel fill) — the panel exists, the text inside it doesn't read. Why: end screen uses chunkyText with outlineWidth = 0 on white text against #1d2a6e at 17px — fine in motion, killed by JPEG compression + contact-sheet downscale. Fix: in drawEndScreen() (lines 1015–1027), bump value text 17px → 22px, add outlineWidth=2 to both label and value chunkyText calls, widen the panel from goldPanel(ctx, 440, 270, 400, 210, 18) to goldPanel(ctx, 390, 250, 500, 240, 18). ~15 min.
